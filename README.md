# MB5370 Module 2: Data Science in R

This repository contains code and data, and other supplementary files from Module 2 workshops.
The [code](code) folder contains all R Quarto markdown files I created during each workshop.
The [data](data) folder contains .csv, .txt, and .xlsx files that I uploaded to R to complete workshops 1 through 4, including the workshop 2 exercise.

- [Workshop 1](code/MB5370_Module02_Workshop1.qmd) is a basic introduction to importing, cleaning/wrangling, and visualising data in R.
- [Workshop 2](code/MB5370_Module02_Workshop2.qmd) covers R coding concepts such as pivoting data frames to make them longer or wider, separating data frame columns into multiple columns, combining multiple data frame columns into one column, wrangling strings and dates using the `stringr` and `lubridate` libraries, and how to handle missing values in data frames.
- [Workshop 3](code/Module2_Workshop3.qmd) is an exercise where I found a figure from a scientific paper, extracted the data, and reconstructed the figure using concepts covered in workshop 1 and 2. I extracted data that I used to map trends in global fisheries over time in terms of fish stock status (fully, partially, or under exploited).
- In [Workshop 4](code/Module2_Workshop4.qmd) I wrangled multiple datasets to map how copepod species richness in Australia has changed with variation in water temperature.

The Quarto markdown file for the workshop 2 exercise can be found [here](code/Module2_Workshop2_exercise.qmd).
